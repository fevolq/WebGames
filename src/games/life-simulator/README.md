# 人生模拟器

独立入口 `/life-simulator`。以手记形式呈现从出生到终章的人生，提供现代、古代、修仙三个背景。

## 游玩

- 先建立出生档案，填写姓名并分配初始属性，再点击现代、古代或修仙背景卡片直接进入人生，无需额外开始按钮。六项属性基础为 1、上限为 10，额外预算 30；体魄/魅力/心性每级 1 点，悟性/家境每级 2 点，气运每级 3 点。
- 支持随机分配与重置，也允许主动不分完点数。
- 每次选择先显示结果，再翻到下一事件。风险行动显示成功率，条件不足的行动保留说明。
- 每个背景有六种出生环境，共十八种。家境影响出现权重但不锁死出身；地点、家庭、健康、生计、心境与人物关系也随出生种子变化。
- 每个背景有六条发展方向，每条有三个递进事件。成年时按当前属性、童年兴趣和出生环境加权给出三种机会；也可先过平常生活，中途再改道。旧关系、支线和手记不会重置。
- 每个背景有四组跨年份支线，每组包含相遇、转折、回响。最多同时承担两段未结束的约定；拒绝或主动结束后不再出现后续。成功与受挫会改变回响及结局旧物。
- 每个背景有六种正面、六种负面突发际遇。发生主要靠随机，属性与气运只小幅改变权重（0.8–1.25 倍）；高气运也会遇到意外。
- 新人生有 165 个可抽取的编写事件：36 个成长/日常事件、54 个发展方向事件、36 个支线阶段、36 个突发际遇、3 个修行突破事件。另有出生、道路选择、改道、平静时光与告别；不是联网即时生成文字。
- 年龄间隔和初始寿元随机变化；新修仙人生成功筑基、结丹后才延寿，未突破仍在凡人寿元内结束。长寿角色的故交以师承、后人和旧日牵挂继续呈现。
- 健康归零提前结束；生计代表生活余裕，心境代表内在状态，不提供统一人生总分。
- 自动保存当前进度与开局草稿，往世录保留最近 12 段完整人生，可导出纯文本生平。在手记页也可导出未完人生。
- 重新开始未完人生须确认，已完成的记录仍保留。返回大厅沿用路由层的悬浮导航。

## 代码与扩展

- `model.ts` 定义事件、选择、属性、影响和生平模型。
- `stories/origins.ts` 定义出生环境及人物关系；`paths.ts` 定义十八条发展方向；`sideStories.ts` 定义十二组支线；`incidents.ts`、`everyday.ts` 定义突发际遇与日常。突发列表每个世界前六条为正面，后六条为负面。
- `stories/modern.ts`、`ancient.ts`、`cultivation.ts` 保留世界元数据与旧版章节，供旧档重演。
- `journey.ts` 按年龄、当前属性、需求、兴趣、关系和已做选择筛选事件，先抽类别再抽事件，避免大池淹没正在进行的支线。每次人生最多 96 个事件，事件不重复，支线必须满足前置选择及时间间隔。
- `engine.ts` 管理预算、条件、行动效果和新旧剧情入口。`random.ts` 提供确定性随机流，出生、抽事件、风险结算都可重演。选中的事件与机会列表固定，刷新不重新抽取。
- `storage.ts` 继续使用 `life-simulator:save:v1`。每份人生配方新增 `storyVersion`：缺失或为 1 时按原剧情读取，为 2 时按新流程读取；旧档与新档可以共存。保存初始配置、出生种子、事件/选择 ID 和展示阶段，读取时重演并验证，拒绝非法版本、预算、选择、顺序和阶段。单条往世录损坏不会丢弃有效的当前人生。
- `WorldScene.tsx` 为本地矢量插画；游戏不使用外部字体、图片或生成服务。

添加新情节时，至少提供一个无门槛选项，并验证各条路线都有递增年龄及终章。发布后修改事件顺序、ID、效果、权重或随机消费规则时，必须保留对应剧情版本实现或明确迁移，避免旧选择记录被错误重演。

测试覆盖三百段随机人生的年龄、结局与多样性，属性和机会关联、意外权重边界、十二组支线的前置/拒绝/回响、改道、寿元、致命意外、逐步存档重演与篡改拒绝、旧档兼容，以及三个世界从出生到往世录的完整 UI 流程。
