# 游戏模块

每个小游戏放在 `src/games/<slug>/index.tsx`，默认导出一个 React 组件。
`slug` 必须与 `src/catalog/games.ts` 中的登记信息一致。

各款游戏均独立实现自己的页面。游戏目录中的职责划分：

- `engine.ts`：纯游戏规则、胜负判断、计分和状态 reducer，不依赖 React。
- `storage.ts`：版本化存档校验与本地保存，使用带 slug 前缀的键。
- `index.tsx`：独立游戏页面、键盘和鼠标交互，卸载时清理监听。
- `Game.module.css`：游戏自己的布局与样式，不依赖大厅布局或公共游戏模板。
- 同目录测试覆盖规则、存档、实际交互；大厅测试覆盖封面入口与返回。

目前七款游戏均已完成并设为 `available`：

| 目录 | 独立页面与交互 | 本地保存内容 |
| --- | --- | --- |
| `life-simulator/` | 人生模拟器：现代、古代、修仙背景，从出生开始分配属性、选择分支、回望生平 | 开局配置、当前人生和最近 12 段完整人生 |
| `2048/` | 2048：几何拼图，支持键盘、方向按钮和棋盘拖动 | 棋盘、计分、最高纪录和一步撤销 |
| `snake/` | 贪吃蛇：复古掌机，十字按键与开局速度选择 | 最高纪录 |
| `block-drop/` | 俄罗斯方块：霓虹街机，待落队列、升级进度与落点辅助 | 当前局面、方块队列、行数、计分和最高纪录 |
| `space-run/` | 星际穿梭：全屏飞行场景，点击航道与护盾、航程仪表 | 最高纪录 |
| `minesweeper/` | 扫雷：勘测工作台，坐标、标旗工具与相邻格提示 | 棋盘、难度、揭开/标旗状态及用时 |
| `reversi/` | 黑白棋：木质棋桌，翻子预览、落子记录与悔棋 | 棋局、人机/双人模式和悔棋历史 |

所有游戏的页面、样式、交互、运行状态、规则、存档及恢复逻辑均留在各自目录内，没有公共游戏模板或页头。大厅和路由层负责展示入口与加载组件，不参与进度管理。路由层提供独立悬浮的右上角设置入口，默认隐藏，鼠标移入或键盘聚焦时出现，菜单内提供返回大厅；该入口不占页面空间，也不读取游戏状态。

`_shared/` 仅包含输入、计时器和焦点生命周期工具，不包含页面、样式或存档。离开页面时各游戏清理自己的计时器和输入监听；实时游戏切出窗口时自动暂停。

新增游戏在完成玩法并通过检查后，才在目录中设置 `status: 'available'` 并移除 `demo`。
所有游戏模块通过 `import.meta.glob` 按需加载，不会直接打包进大厅入口。
